# جامعتي | Jami3ati — المفهوم ونطاق المشروع

## 1. المشكلة
تتوزع المعلومات الجامعية بالمملكة المغربية بين بوابات متعددة:
- بوابات الجامعات الأم (مثل um5.ac.ma أو uca.ma).
- بوابات المدارس والكليات الفردية (مثل ensias.um5.ac.ma أو fsr.ac.ma).
- بوابات الوزارة المعنية والبيانات المفتوحة (data.gov.ma).

هذا التشتت يرهق الطلبة الجدد وأولياء الأمور والطلبة الدوليين، ويجعل التحقق من الروابط الرسمية ومواعيد المباريات أمراً شاقاً وعرضة للمعلومات المغلوطة المنتشرة على شبكات التواصل الاجتماعي.

## 2. الحل المقترح: جامعتي (Jami3ati)
دليل استكشافي موحد يعتمد حصرياً على البيانات المفتوحة والمصادر الرسمية المنشورة:
- **دليل موحد** يعرض علاقات التبعية (مثلاً: ENSIAS تابعة لجامعة محمد الخامس بالرباط).
- **صفر تخمين**: لا يتم اختراع أرقام أو إيميلات؛ إذا لم تتوفر المعلومة في منشور رسمي تترك فارغة مع عبارة "غير متاحة".
- **شفافية تامة**: كل بطاقة تتضمن اسم المصدر الرسمي ورابطه وتاريخ التحقق منه.
- **تشاركية مجتمعية مسؤولة**: زر "الإبلاغ عن معلومة غير صحيحة" يتيح للطلبة اقتراح تصحيحات مشروطة برابط مصدر رسمي.

## 3. الفئات المستهدفة
1. **الطلبة الحاصلون على البكالوريا**: استكشاف المؤسسات حسب المدينة، التخصص، وشروط الولوج.
2. **طلبة الأقسام التحضيرية والشهادات الجامعية**: معرفة مسالك الهندسة ومواعيد المباريات.
3. **أولياء الأمور**: الوصول إلى المواقع الرسمية الموثوقة للمؤسسات.
4. **الطلبة الدوليون**: دليل متكامل باللغتين العربية والفرنسية.
