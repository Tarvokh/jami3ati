# سجل القرارات الهندسية (Architecture & Technical Decisions)

## 1. نموذج هجين للعرض والتشغيل السريع (Hybrid Execution Model)
- **في بيئة المعاينة التفاعلية الفورية**: تم تشغيل واجهة React + TypeScript على خادم Vite مع حالة محلية غنية ومصادر بيانات بصرية حقيقية لتمكين لجان التحكيم والمستخدمين من اختبار كافة السيناريوهات فوراً عبر المتصفح.
- **في بيئة التطوير والإنتاج الكاملة**: تم توفير معمارية الحاويات الكاملة `docker-compose.yml` مع واجهة Python FastAPI، قاعدة بيانات PostgreSQL العلائقية، وPydantic للتحقق الصارم.

## 2. النطاق الميداني الأول ومؤسسات التحقق
- التركيز على قطبين جامعيين رئيسيين للتحقق الدقيق:
  - **جامعة محمد الخامس بالرباط (UM5)** مع مؤسستها الهندسية المرموقة **ENSIAS** في مدينة العرفان.
  - **جامعة القاضي عياض بمراكش (UCA)** مع **كلية العلوم والتقنيات جليز**.
- تضمين عينات واضحة بعلامات `needs_review` و`demo` لشرح كيفية التوسع المستقبلي دون ادعاء الشمولية الزائفة.

## 3. القرار بشأن اللغات وRTL
- استخدام خط `Tajawal` العربي المعتمد والواضح جداً للقراءة الرقمية في اتجاه اليمين لليسار (`dir="rtl"`).
- زر تبديل سلس مع الفرنسية (`dir="ltr"`) مع خط `Plus Jakarta Sans`.
