## 1:30–2:10 — الإثبات (اللحظة)

**افتح بلا تسجيل دخول:**

```
http://127.0.0.1:8000/n/<FACT_ID>
```

> «بلا حساب، بلا JavaScript. العنوان، الرابط الرسمي، تاريخ قراءة المصدر، بصمة SHA-256، الفرق، واللقطة الكاملة. افتح الرابط الرسمي وقارن بنفسك. صفحة `/n/{id}` دائمة: إن تغيّر المصدر غدًا، هذه الواقعة لا تتغيّر.»

**افتح «ما الذي تثبته هذه الصفحة؟»:**

> «`source_url + verified_at` تثبت المحتوى. `DKIM/SPF/DMARC` تثبت فقط أن الرسالة خرجت من نطاقنا. لا نقول إن الوزارة وقّعت المعلومة.»

## 2:10–2:40 — الجرس: التنبيه

**إن كان صندوق Tira مضبوطًا:** افتح البريد، اضغط رابط `/n/{id}`.

> «البريد جرس، وليس المنتج. المنتج هو الدليل.»

**إن لم يكن مضبوطًا:** اعرض صف `notification_deliveries` وقل:

> «الصف جاهز في الطابور، لكن الإرسال الحقيقي يحتاج اعتماد صندوق Tira. لن ندّعي إرسالًا لم يحدث.»

## 2:40–3:00 — الصدق والطلب

**شريحة «حقيقي مقابل مُخطَّط»:**

| حقيقي اليوم | مُخطَّط (لا ندّعيه) |

| **78 اختبارًا** (21 لحلقة الرصد) | ضمان تسليم بلا تشغيل |

## الاحتياطي (60 ثانية) — تغيّر حقيقي على مصدر تقني محلي

> **قُل صراحة:** «الوزارة لا تتغيّر عند الطلب. نُظهر الاكتشاف الآن على صفحة محلية نتحكم فيها. المصدر الرسمي مسجّل أعلاه ولقطته الأولى محفوظة. هذا تدريب على الآلية، وليس ادّعاءً عن مصدر رسمي.»

```powershell
New-Item -ItemType Directory -Force C:\temp\jami3ati-demo | Out-Null
$utf8 = New-Object System.Text.UTF8Encoding($false)
python -m http.server 8099 --directory C:\temp\jami3ati-demo

# المصدر التقني مسجَّل مسبقًا؛ اقرأ معرّفه (وسجّله إن غاب)
$sources = Invoke-RestMethod http://127.0.0.1:8000/api/v1/sources
$srcId = ($sources | Where-Object { $_.url -eq "http://127.0.0.1:8099/" }).id
if (-not $srcId) {
  $body = '{"name_ar":"مصدر تقني للعرض (ليس مصدرًا رسميًا)","url":"http://127.0.0.1:8099/","check_interval_minutes":15,"is_official":false}'
  $src = Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8000/api/v1/sources `
    -Headers @{"X-Jami3ati-Admin"="demo-admin"} -ContentType "application/json" `
    -Body ([Text.Encoding]::UTF8.GetBytes($body))
  $srcId = $src.id
  Invoke-RestMethod -Method Post -Uri "http://127.0.0.1:8000/api/v1/sources/$srcId/poll" `
    -Headers @{"X-Jami3ati-Admin"="demo-admin"}
}

# اكتب قيمة جديدة تختلف عن اللقطة المحفوظة ثم استقصِ → واقعة pending
[System.IO.File]::WriteAllText("C:\temp\jami3ati-demo\index.html",
  "<html><body><h1>إعلان</h1><p>أجل الترشيح: 20 ديسمبر 2026</p></body></html>", $utf8)
Invoke-RestMethod -Method Post -Uri "http://127.0.0.1:8000/api/v1/sources/$srcId/poll" `
  -Headers @{"X-Jami3ati-Admin"="demo-admin"}
```

> إن لم تظهر واقعة، فالقيمة طابقت اللقطة المحفوظة؛ اكتب تاريخًا مختلفًا واستقصِ مرة أخرى.
